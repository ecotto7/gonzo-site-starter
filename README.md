# Gonzo site starter

Plain HTML, CSS, and JavaScript for a Netlify site. There is no build step.

## New site

1. On GitHub, choose **Use this template** and create the new repository.
2. In Netlify, import that repository. Leave the build command empty. The publish directory is `.` (`netlify.toml` already sets this).

Deploys happen by pushing to `main`. Do not run a production deploy command unless you mean to spend a deploy credit.
